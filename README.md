# Paradise Nursery Shopping Application

## Project Name
**Paradise Nursery** — Online Plant Shop

## Description
Final project for IBM's "Developing Front-End Apps with React" course. Paradise Nursery is a dynamic React web application for an online plant shop where users can browse houseplants across multiple categories, view plant details (thumbnail image, name, description, and price), add plants to a shopping cart, and manage cart items.

## Features
- Landing page with the Paradise Nursery company name and a "Get Started" button
- About Us page with company details
- Product listing page with 3 plant categories and 18 houseplants
- Add to Cart buttons that disable after adding and update the cart icon count
- Shopping cart page with quantity increase/decrease, item removal, per-plant totals, and grand total
- Checkout button and Continue Shopping button
- Navigation bar on all pages with Home, Plants, and Cart links
- Redux Toolkit slice for cart state management

## Tech Stack
- React (Vite)
- Redux Toolkit + React Redux
- React Router DOM
- CSS
